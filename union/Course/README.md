# section-reading-service

Microservicio para consultar secciones de cursos (Course Sections).

### 🚀 Endpoints

- `GET /sections`: Devuelve todas las secciones.
- `GET /sections/{id}`: Devuelve los datos de una sección por ID.

### 🛠️ Tecnología
- Go (Gin)
- PostgreSQL
- Docker

### 🔌 Ejemplo de uso en Postman

**GET http://localhost:3011/sections**

**GET http://localhost:3011/sections/{uuid}**
